# 1분 피칭 슬라이드
총 5장으로 구성된 1분 피칭 슬라이드를 만들어주세요.
청중은 평가자·심사위원·동료이며, 목적은 자기 작품을 자신감 있게 소개하는 것입니다.

## 브랜드/작품 정보
- 이름: [HIKER/VISUAL CONCEPT]
- 슬로건: [스타일과 기능의 완벽한 교차점]
- 컨셉: [일상과 기능성의 밸런스가 갖춰진 하이브리드 스타일]
- 타깃 페르소나: [20-40대 직업은 it업계 개발자, 기능성, 하이퀄리티 스타일에 관심 많은 소비자, 취미는 하이킹+등산]

## 비주얼 아이덴티티
- 컬러 팔레트: [#5B6B7C / #EFE6D5 / #7C8471 / #4A3240 / #D4D6D8]
- 무드: [HIGH TECH / MODERN / CONTEMPORARY/ MINIMAL / URABAN OUTDOOR]
- 무드 보드: 첨부한 이미지 참고
- 로고: 첨부한 이미지 참고

## 5장 구조
p1. 표지
- 슬라이드 중앙에 브랜드 이름 + 슬로건
- 임팩트 있는 시각 구성

p2. 이 브랜드/작품이 향한 사람
- 페르소나 설명 (구체적으로)
- 그들의 일상 고민

p3. 컨셉과 풀어낸 방식
- 컨셉 한 줄을 큰 글씨로
- 무드보드 이미지를 함께 배치

p4. 비주얼 시그니처
- 컬러 팔레트
- 로고 활용 예시

p5. 앞으로의 계획 또는 다짐
- 아래 내용을 배치
- 내용: [이 작업 과정을 포트폴리오로 정리해서, 원하는 직무에 지원할 때 활용하고 싶습니다.]
- 마무리 인사 "감사합니다" 작게 하단에
